# HU-02 – Alerta de stock mínimo

**Como** responsable de depósito, **quiero** recibir una alerta cuando el stock de
un insumo baja del mínimo definido, **para** reponerlo antes de que se interrumpa
la producción.

## Criterios de aceptación
- Cada insumo tiene un stock mínimo configurable (campo `stock_actual` de `Insumo`).
- La alerta es visible al registrar movimientos de stock.
- El ingreso de insumos actualiza el stock y recalcula la alerta.
