# HU-03 – Reporte de trazabilidad

**Como** responsable de calidad, **quiero** generar el reporte de trazabilidad de un
lote aprobado, **para** presentarlo ante SENASA o la certificadora orgánica en una
auditoría.

## Criterios de aceptación
- El reporte muestra el lote, los insumos consumidos, sus proveedores y el
  certificado orgánico vigente de cada uno.
- Solo se puede generar para lotes con `aprobado_calidad` verdadero.
- El reporte se puede exportar a PDF.
